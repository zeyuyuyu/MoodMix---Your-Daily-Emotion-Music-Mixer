# MoodMix

MoodMix is an engaging web app that lets users create and share unique music mixes based on their daily emotions. Users select their current moods using an intuitive emoji interface, and the app generates a custom music mix visualization that can be shared on social media.

Key Features:
- Interactive mood selection via emojis
- Real-time audio-visual music generation
- Social sharing capabilities
- Daily mood tracking statistics
- Vibrant, responsive design

Tech Stack:
- HTML5 Canvas for visualizations
- Web Audio API for sound synthesis
- Local Storage for mood tracking
- Responsive CSS animations
